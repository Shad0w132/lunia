# Луния 0.2 — версия для iPhone (офлайн PWA)

Это порт нативного Android-приложения **Луния 0.2** под iPhone в формате **Progressive Web App (PWA)**.
- **100% офлайн**: все данные хранятся только в памяти iPhone (`localStorage`), без сервера и аккаунта.
- **Математика Engine v2**: байесовский прогноз цикла, месячных и лютеиновой фазы (`Bayes.kt` + `EngineConstants.kt`), ядро фертильности, режимы планирования, беременности и гормональных таблеток.
- **Весь контент из оригинала**: 39 статей, 29 историй, 6 мини-книг, полный каталог симптомов и шрифты Manrope.
- **Не слетает через 7 дней** (в отличие от `.ipa`, подписанных бесплатным Apple ID).

## Как установить на iPhone (2 способа)

### Способ 1 — через бесплатный HTTPS (GitHub Pages / Cloudflare Pages / Netlify Drop) — рекомендуется
HTTPS нужен iOS для полноценной работы Service Worker (офлайн-кэша):
1. Перетащи всю папку `lunia-ios-pwa` на [app.netlify.com/drop](https://app.netlify.com/drop) или загрузи в репозиторий GitHub и включи **GitHub Pages**.
2. Открой полученную ссылку в **Safari** на iPhone.
3. Нажми кнопку **«Поделиться»** (квадрат со стрелкой вверх) → **«На экран «Домой»»** → **«Добавить»**.
4. Готово: Луния появится как обычное приложение с иконкой и после первого открытия будет работать полностью без интернета.

### Способ 2 — локально по Wi-Fi с ПК на Windows
1. Убедись, что ПК и iPhone в одной сети Wi-Fi.
2. Открой папку `lunia-ios-pwa` и запусти в терминале:
   ```bash
   python server.py
   ```
3. Открой в Safari на iPhone адрес вида `http://192.168.x.x:8080`, который выведет скрипт, и добавь на экран «Домой».
*(Примечание: по обычному HTTP iOS не активирует Service Worker, поэтому для автономной работы без ПК лучше использовать Способ 1).*
